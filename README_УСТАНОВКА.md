# КАРТОЧКИ — бесплатное приложение для изучения слов

Готовое PWA: без подписки, регистрации, сервера и внешних API. Код, таблицы и прогресс хранятся на устройстве пользователя. Включён пример из 6 слов.

## Что внутри

- Список слов → автоматические карточки: `Apple — яблоко` (каждая пара на новой строке).
- Импорт TXT, CSV, TSV и XLSX (первый лист, первые два столбца).
- Перевод в обе стороны или случайное смешивание направлений.
- Карточки «Показать перевод / Знаю / Не знаю» и проверка письменного перевода.
- Интервальное повторение **отдельно для каждого направления**.
- Разные наборы и языки; поиск, редактирование, удаление, экспорт CSV.
- Статистика и JSON-резервная копия с полным прогрессом.
- После первой загрузки с HTTPS интерфейс работает без интернета.

## Самый простой способ установить на телефон — GitHub Pages

1. Создайте БЕСПЛАТНЫЙ аккаунт на https://github.com/ (если его нет).
2. Создайте новый **Public** репозиторий, например `kartochki`. На бесплатном тарифе GitHub Pages работает для публичных репозиториев.
3. Распакуйте ZIP. Загрузите **содержимое** папки `kartochki-pwa` в корень репозитория (важно: `index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `service-worker.js`, а также папки `assets` и `vendor`).
4. В репозитории откройте **Settings → Pages** → **Build and deployment** → **Deploy from a branch**. Выберите `main` и папку `/(root)`, нажмите **Save**.
5. Откройте опубликованную страницу GitHub Pages по адресу вида `https://ВАШ-ЛОГИН.github.io/kartochki/` (адрес зависит от имени репозитория).
6. На Android в Chrome нажмите меню **⋮ → Установить приложение** или **Добавить на главный экран**. На совместимых браузерах также появится кнопка «Установить» в интерфейсе.
7. Один раз откройте приложение при наличии интернета. После этого оно работает офлайн (импорт XLSX также офлайн).

### Проверка на компьютере, без публикации

Не открывайте `index.html` двойным щелчком: PWA-установка и сервис-воркер не работают по `file://`.

В папке приложения запустите:

```bash
python -m http.server 8000
```

И откройте в браузере `http://localhost:8000`.

### Форматы импорта

Текст (каждая пара с новой строки):

```text
Apple — яблоко
House — дом
Remember — помнить
```

CSV: первые два столбца, разделитель `;`, `,` или табуляция. Для Excel: файл `.xlsx`, **первый лист**, **столбец A — слово**, **столбец B — перевод**; первая строка с заголовками «Слово / Перевод» пропускается. Старые файлы `.xls` сначала сохраните как `.xlsx`.

### Сохранение

Приложение не синхронизируется между устройствами: на телефоне и ПК будут раздельные словари. Для переноса используйте **Настройки → Скачать копию .json** и **Настройки → Загрузить копию**. При очистке данных браузера словарь может исчезнуть. Экспортируйте резервные копии регулярно.

### Интервальное повторение

«Знаю»: следующий показ через 1, 3, 6+ дней (интервал растёт). «Не знаю»: ещё одна попытка в текущей тренировке и повторение в будущем. В тренировке «К повторению» попадают новые или просроченные карточки. Русский → английский и английский → русский имеют независимые интервалы.

### Технические детали

Статические HTML/CSS/JS, IndexedDB, Service Worker, Web App Manifest. Внешние подключения, регистрация и аналитика отсутствуют. JSZip (MIT license, текст лицензии в `vendor/JSZIP-LICENSE.md`) используется только для разбора XLSX прямо в браузере. Голосовое произношение зависит от доступности синтезатора речи на устройстве и от установленных голосов.
